## 🎯 Why Arrays & Hashing Matter

<div align="center">

| 🔥 Insight | 💬 Why It's Critical |
|:---|:---|
| **Foundation of All DSA** | Arrays and hash maps appear in nearly every advanced topic — Graphs, Trees, DP, and more. |
| **Top Interview Category** | FAANG/MAANG companies consistently test hashing patterns in screening rounds. |
| **O(1) Lookup Power** | Hash maps turn brute-force O(n²) problems into elegant O(n) solutions. |
| **Pattern Recognition** | Mastering frequency counting, prefix sums, and grouping builds a transferable mental model. |
| **Real-World Applications** | Caching, indexing, deduplication, data aggregation — all powered by hashing. |

</div>

> Arrays & Hashing is **Step 1** in every serious DSA roadmap for a reason — it builds the algorithmic intuition that unlocks every topic that follows.

## 🧠 Core Concepts Mastered

<div align="center">

| 💡 Concept | 📝 Description | 🔗 Applied In |
|:---|:---|:---|
| **HashMap** | Store key-value pairs for O(1) average lookup, insert, and delete | Two Sum, Group Anagrams, Top K Frequent |
| **HashSet** | Track unique elements and check membership in O(1) time | Contains Duplicate, Longest Consecutive, Valid Sudoku |
| **Frequency Counting** | Build a frequency map to compare or rank element occurrences | Valid Anagram, Top K Frequent Elements |
| **Prefix & Suffix Products** | Precompute running products to answer range queries without division | Product of Array Except Self |
| **Matrix Manipulation** | Traverse and mutate 2D arrays in place using smart index tracking | Valid Sudoku, Set Matrix Zeroes, Spiral Matrix |
| **In-Place Array Reversal** | Rotate arrays in O(1) space by strategically reversing subarrays | Rotate Array |
| **Bucket Sort (Linear)** | Map frequencies to index-based buckets to avoid O(n log n) sorting | Top K Frequent Elements |
| **Sequence Detection** | Use a HashSet to detect sequence starts for O(n) consecutive runs | Longest Consecutive Sequence |
| **Boundary-Driven Traversal** | Track four shrinking boundaries to spiral through a matrix cleanly | Spiral Matrix |
| **Linear Array Traversal** | Single-pass pointer techniques for range and interval problems | Summary Ranges |

</div>

## ⚡ Complexity Highlights

<div align="center">

| # | Problem | Time Complexity | Space Complexity | Approach |
|:---:|:---|:---:|:---:|:---|

| 03 | Contains Duplicate | `O(n)` | `O(n)` | HashSet membership |
| 04 | Group Anagrams | `O(n · k log k)` | `O(n · k)` | Sorted key HashMap |
| 05 | Top K Frequent Elements | `O(n)` | `O(n)` | Freq map + bucket sort |
| 06 | Product of Array Except Self | `O(n)` | `O(1)` | Prefix/suffix pass |
| 07 | Valid Sudoku | `O(1)` | `O(1)` | Fixed 9×9 HashSet scan |
| 08 | Longest Consecutive Sequence | `O(n)` | `O(n)` | HashSet + seq start |
| 09 | Rotate Array | `O(n)` | `O(1)` | Triple reversal |
| 10 | Set Matrix Zeroes | `O(m · n)` | `O(1)` | In-place flag markers |
| 11 | Spiral Matrix | `O(m · n)` | `O(1)` | Four-boundary shrink |
| 12 | Summary Ranges | `O(n)` | `O(1)` | Single-pass pointer |

## 🚀 How To Run

### Prerequisites

- Java JDK 11 or higher installed
- IntelliJ IDEA (recommended) or any Java IDE
- Git installed

### Clone the Repository

```bash
git clone https://github.com/Yaswanth-Kumar-dev/Arrays-Hashing.git
cd Arrays-Hashing
```

### Open in IntelliJ IDEA

```
1. Open IntelliJ IDEA
2. File → Open → Select the cloned folder
3. Navigate to: ArraysAndHashing/
4. Open any .java file (e.g., TwoSum.java)
5. Right-click the file → Run 'ClassName.main()'
```

### Compile & Run from Terminal

```bash
# Navigate to the source folder
cd ArraysAndHashing

# Compile a specific solution
javac TwoSum.java

# Run it
java TwoSum
```

> 💡 Each solution file is self-contained and can be run independently. Add your own `main()` test cases to verify outputs.
